# Week 2 — Python Fundamentals & Problem Solving

Week 2 took me deeper into Python programming. Having completed the initial orientation, I began working more seriously with Python and learning the basic building blocks required to write programs.

I learned about fundamental Python concepts such as variables, data types, strings, numbers, lists, tuples, dictionaries, operators, and basic input and output. These concepts may appear simple individually, but I began to understand how they form the foundation of more advanced programming and Data Science work.

One of the most valuable parts of the week was learning how to approach programming problems logically. Rather than simply trying to memorize Python syntax, I began thinking about what a program needs to accomplish, what information it needs to receive, what operations need to be performed, and what result should be produced.

I also worked with conditional statements and loops. These introduced me to the idea of controlling the flow of a program based on different conditions and repeating operations when necessary. Through practical exercises, I started seeing how simple programming concepts can be combined to solve increasingly complex problems.

Functions were another important area of learning. I began understanding how functions can help organize code into reusable blocks, making programs easier to understand, maintain, and expand.

A significant part of my learning experience was debugging. Some of my programs did not work correctly on the first attempt, and I had to identify errors such as incorrect syntax, missing brackets, indentation problems, incorrect operators, and other programming mistakes. This helped me understand that errors are a normal part of programming and that debugging is an essential skill rather than something to be avoided.

The practical exercises also helped me become more comfortable writing Python code independently instead of relying entirely on examples.

By the end of Week 2, I had developed a stronger foundation in Python and had begun to understand how programming can be used as a tool for solving real-world problems. I also became more confident in reading code, identifying errors, and breaking problems into smaller steps.

# Week 3 — Python Modules, Dates, Mathematics, JSON & Virtual Environments

Week 3 expanded my Python knowledge beyond the basic programming concepts I had learned during the previous week. I was introduced to several practical Python features that are important when developing real applications and working with data.

One of the major topics was Python modules. I learned that Python provides many built-in modules that contain useful functions and tools, allowing developers to perform tasks without having to write everything from scratch. I worked with modules such as math and datetime and began understanding how importing modules can extend the capabilities of a Python program.

I also learned about mathematical operations in Python, including working with functions such as square roots and constants such as math.pi. These exercises helped me understand how Python can be used for calculations that are relevant to scientific and analytical work.

Dates and time were another important area of Week 3. I learned how to work with the datetime module and use dates to perform practical tasks such as retrieving the current year and calculating information based on dates. This showed me how programming can interact with real-world information rather than only working with static values.

I was also introduced to JSON and learned how Python can work with JSON data. Understanding JSON is particularly important because it is widely used for exchanging structured information between applications, websites, APIs, and other systems. I practiced converting Python data structures into JSON-compatible formats and understanding how structured data can be represented.

Another useful topic was pip, Python's package management system. I learned how packages can be installed and managed to extend Python's functionality beyond its built-in capabilities.

I also learned about exception handling using try and except. This introduced me to a more reliable way of writing programs that can respond appropriately when something goes wrong instead of simply stopping with an error.

Virtual environments were another important concept. I learned why separate Python environments are useful for managing project dependencies and avoiding conflicts between different projects. I also practiced working with virtual environments while using Visual Studio Code and the command line.

Throughout the week, I continued practicing by writing small programs and solving exercises. Debugging remained an important part of the process because I encountered issues involving syntax, indentation, brackets, operators, and environment setup.

Week 3 was particularly valuable because I began seeing Python as more than a beginner programming language. I started seeing how its modules, packages, data formats, and environment-management tools fit together into a professional development workflow.

# Week 4 — Research, Problem Identification & Data-Driven Thinking

Week 4 expanded my learning beyond programming and introduced me to the importance of research and structured problem-solving in Data Science.

One of the important lessons I began to appreciate was that technical skills alone are not enough to solve meaningful problems. Before collecting data, writing code, or building a machine learning model, it is necessary to understand the problem that needs to be solved. Good Data Science begins with asking good questions.

I learned about the importance of identifying a clear research problem and understanding the context surrounding that problem. This involves examining what is already known, identifying gaps in existing knowledge, defining the objectives of an investigation, and determining what information or data may be required.

I also began understanding the relationship between research questions, data collection, analysis, and conclusions. A well-defined research question helps determine what data should be collected and what analytical methods may be appropriate. Without a clear question, it can be easy to collect large amounts of information without producing useful insights.

Another important area was learning how to approach information critically. Not every piece of information available online is reliable, accurate, or suitable for research. I began developing an awareness of the importance of evaluating sources, checking evidence, comparing information, and distinguishing between assumptions and facts.

The week also helped me understand how research connects with Data Science. Data Scientists do not simply manipulate datasets; they investigate questions using evidence. The process involves defining a problem, collecting relevant information, preparing the data, analyzing it, interpreting the results, and communicating the findings.

I also began thinking more about real-world applications of data. Problems in business, finance, education, healthcare, governance, technology, and many other sectors can be approached using data when the right questions are asked and appropriate methods are applied.

Another valuable lesson was the importance of documentation. Recording the research process, assumptions, sources, methods, observations, and conclusions makes work easier to understand, reproduce, evaluate, and improve.

By the end of Week 4, I had begun to see Data Science from a broader perspective. Programming is an important tool, but the ultimate goal is to use programming and analytical methods to investigate problems and produce meaningful insights.

Week 4 therefore helped connect the programming knowledge I had developed during the first three weeks with the larger purpose of Data Science: using structured thinking, evidence, data, and technology to understand problems and develop useful solutions.
